"고래들의 비상" / GOBIBI × SANG#MUNG
TEN CETACEAN SPECIES / 고래류 10종

이 웹 작품은 고래류 10종의 외형과 서로 다른 수영 동작을 실시간 3D로 표현합니다.
스킨 애니메이션 GLB 5종과 직접 모델링한 절차적 3D 표현 5종으로 구성됩니다.
영화급 스캔·촬영 모델이나 자연 다큐멘터리라고 주장하지 않습니다.
This experience presents whales only; no 2D character overlay is rendered.

직접 제작 3D 표현 / Original procedural anatomical studies:
- 참고래 / Fin whale / Balaenoptera physalus
- 귀신고래 / Gray whale / Eschrichtius robustus
- 밍크고래 / Common minke whale / Balaenoptera acutorostrata
- 일각고래 / Narwhal / Monodon monoceros
- 흰고래 / Beluga / Delphinapterus leucas
Original geometry and procedural skin by GOBIBI × SANG#MUNG production.
Separate hand-authored body profiles, pectoral fins, flukes, dorsal structures, pigmentation and continuous tail/body deformation. These are original 3D interpretations, not reused third-party scans and not one model recoloured to claim different species.

크기 비교 및 소개순 / Size and editorial order:
대왕고래24m / 참고래21m / 향고래16m(수컷) / 혹등고래14.5m / 귀신고래14m / 밍크고래8.5m / 범고래7m(수컷) / 일각고래4.5m / 흰고래4m / 큰돌고래3m.
These lengths are chosen representative individuals for the visual comparison, not population means, species maximum records, or a universal adult size distribution. Actual size varies by sex, population and region. Narwhal body length excludes the additional tusk.
Comparison mode uses a common scale and equal camera distance; flight mode uses perspective and close approaches. "Familiar first" is a curated introduction order, not a measured global popularity ranking.
