# AX4U Books: AI-Native Publishing Automation System

An end-to-end multi-agent orchestration SaaS platform designed to eliminate manual bottlenecks in traditional independent publishing. By minimizing human intervention, the system autonomously executes the entire lifecycle of book production—spanning from initial planning, content design, layout orchestration, administrative processing, to multi-channel distribution.

**Repository URL:** [https://github.com/ax4u/ax4u-books.git](https://github.com/ax4u/ax4u-books.git)

---

## 1. Core Architecture & Technology Stack

The platform utilizes a hybrid pipeline architecture where generative AI capabilities are dynamically integrated with and controlled by deterministic systems:
* **Planning & Text Generation:** OpenAI GPT-5.6 Multi-Agent Core
* **Asset & Image Synthesis:** ComfyUI API (Stable Diffusion / ControlNet)
* **Layout & Systems Orchestration:** Python (Deterministic Typesetting, ReportLab, SCM Protocols)

## 2. Comprehensive AI Integration (Codex & GPT-5.6)

As mandated by the submission guidelines, this section highlights the technical implementations and roles of OpenAI Codex and GPT-5.6 within the platform architecture.

### A. System Orchestration & Code Synthesis via OpenAI Codex
OpenAI Codex was extensively utilized during the development phase to construct the underlying multi-agent coordination layer and bridge components:
* **Deterministic Code Generation:** Codex synthesized complex Python modules responsible for converting abstract JSON layout schemas into pixel-perfect PDF documents using precise coordinates. This bypassed the native spatial awareness limitations of pure visual LLMs.
* **API Integration Wrappers:** Automated generation of boilerplate integration components connecting the core system to external systems, including the ComfyUI API schema and the B2B distribution endpoints.

### B. Core Cognitive Engine via OpenAI GPT-5.6
GPT-5.6 serves as the primary cognitive orchestration layer, powering multiple autonomous agents through specialized Prompt Engineering and Structured JSON outputs.
